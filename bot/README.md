# Telegram Bot (aiogram) — анкета + админка

Бот на Python (aiogram) с:
- меню на inline-кнопках
- анкетой на FSM (4 шага) + кнопки Назад/Отмена
- сохранением анкет в SQLite
- админ-командой `/forms` для просмотра последних анкет

## Функции
- `/start` — показать главное меню
- `📝 Анкета` — заполнить анкету (имя/возраст/город/цель)
- `/myid` — показать ваш Telegram ID
- `/forms` — (только админ) показать последние анкеты
